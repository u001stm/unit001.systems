# UNIT / MA — Design System / Core Principle

## LESS EFFORT. MORE POSSIBILITY.

**MA is the absence of unnecessary effort.**

Дизайн UNIT001 минимизирует не только визуальный шум, но и работу, внимание и число решений пользователя. Сложность остаётся внутри системы; снаружи — ясный результат и контроль.

### Проверка каждого паттерна и компонента

1. Можно ли устранить это действие или выполнить его автоматически?
2. Нужно ли показывать эту информацию прямо сейчас?
3. Сохраняется ли ясность, доступность и возможность исправить ошибку?
4. Даёт ли решение измеримую пользу, а не только эффект новизны?

### Метрики

Сравнивать с прежним сценарием: количество действий, активное время, необходимость контроля, частоту ошибок и качество результата.

### Правило

Не добавлять AI, интерфейс или анимацию ради демонстрации технологии. Инновация должна уменьшать усилия либо открывать полезную возможность.
